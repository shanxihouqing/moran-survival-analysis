# CT spatial heterogeneity and survival modelling

This repository contains the analysis code for a survival-modelling study based on CT-derived intratumoural heterogeneity features. The workflow includes development, internal validation, independent external validation, model evaluation, and SHAP-based interpretation.

## Main files

- `molan_github.R`: complete survival-modelling and external-validation workflow.
- `redraw_shap_publication.R`: regenerates publication-ready SHAP figures without retraining the models.
- `MORAN_INDEX_METHOD.md`: definition, classification rules, and interpretation of the Moran's I habitat analysis.

## Cohorts

- `development_data`: development cohort used for model training and internal splitting.
- `validation_data`: internal validation subset drawn from the development cohort.
- `external_data`: independent external validation cohort.

The data files are not included in the repository. Paths are configured with environment variables:

```r
Sys.setenv(
  MOLAN_DEVELOPMENT_DATA = "data/development_cohort.sav",
  MOLAN_EXTERNAL_DATA = "data/external_validation_cohort.sav",
  MOLAN_OUTPUT_DIR = "results"
)
source("molan_github.R")
```

## Moran's I interpretation

The imaging workflow classifies tumour voxels into High–High, Low–Low, High–Low, Low–High, and non-significant habitats using local Moran's I and voxel intensity relative to the tumour mean. See [MORAN_INDEX_METHOD.md](MORAN_INDEX_METHOD.md) for the formula, spatial-weight definition, classification rules, reporting requirements, and cautious biological interpretation.

## SHAP figures

After SHAP objects have been generated by the main workflow, publication figures can be recreated with:

```r
source("redraw_shap_publication.R")
```

The default input directory is `results/explainability/SHAP`, and figures are written to `results/explainability/SHAP_publication` in PDF, SVG, TIFF, and PNG formats.

## Intended use

This code is intended for research and reproducibility. Model predictions and imaging habitat interpretations must not be used as a substitute for clinical judgement or histopathological confirmation.
